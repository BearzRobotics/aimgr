# 0009: Bundled catalog, access labels, good-for tags, browse

Status: accepted. Date: 2026-11-08.

## Bundled catalog
`config/models.toml` is generated by `tools/catalog-gen/gen.py` (dev-time, network) from public
metadata and committed as a dated snapshot (150 entries on 2026-11-08): popular Ollama library models
(each `name:size` tag verified against registry.ollama.ai, real download size from the manifest),
cloud variants, top GGUF repos of well-known organizations (Hugging Face API; description built only
from API metadata), 40 abliterated GGUF repos and 7 abliterated community models from the Ollama
registry. Hand-written entries live in `tools/catalog-gen/pinned.toml`. aimgr itself never runs the generator.
The landscape moved past the author's knowledge (e.g. Qwen3.8, gemma4), which is why entries come from
registry metadata and not from memory.

## access
`open` (no account to download, runs offline afterwards), `signin` (gated HF repo: account, accepted
license, HF_TOKEN; offline afterwards), `cloud` (Ollama cloud; remote, sign-in + API usage, never offline).
Sources: HF `gated` flag; Ollama `*-cloud` tags / cloud badge (CSS class bg-cyan-50 on the library page).
Online search/browse results carry `access=signin` when the API reports a gated repo. Entries without an
access field (user catalogs, unknown models) show nothing rather than a guess.
Enforcement: `chat`/`serve` and the TUI refuse cloud models (offline-first); pull/update print the access
explanation and warn when HF_TOKEN is unset for gated repos.

## good-for tags (use_cases)
Controlled vocabulary: coding, reasoning, vision, tools, chat, long-context, small, math, multilingual,
creative-writing. Derived from evidence only: name patterns, Ollama capability badges, Hugging Face tags,
GGUF context length (>= 128k), parameter count (<= 4B). They are "suited for" hints, NOT benchmarks, and the UI
says so. Filters: `list --use TAG`, TUI `t`; `list --access`, TUI `f`.

## browse
`aimgr browse [--sort trending|downloads|recent]` and TUI `N` (cycles sorts) list GGUF text-generation repos
without a query, as a job. Results are unvetted third-party repositories.

## Limits
Snapshot goes stale; derived tags can be wrong (e.g. HF tags make some general models "coding"); access is
unknown for models not in the catalog; abliterated listings are unvetted uploads and the "abliterat" name
heuristic still applies. Custom `heretic`/`uncensored` fine-tunes are not tagged abliterated unless the name says so.
